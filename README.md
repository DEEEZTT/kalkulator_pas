# Kalkulator / Calculator

Aplikasi web untuk menghitung dua angka dengan penjumlahan, pengurangan, perkalian, atau pembagian.

## Cara menjalankan / How to run

1. Buka `index.html` di browser.
2. Masukkan angka pertama dan kedua.
3. Pilih operasi: Addition, Subtraction, Multiplication, atau Division.
4. Baca hasil di field **Hasil / Result**.

Open `index.html` in a web browser. Enter two numbers, choose an operation, and read the result.

Field menerima angka negatif dan desimal. Titik digunakan untuk pemisah ribuan; koma digunakan untuk desimal. Contoh: `1.000.000` dan `2,5`. Huruf dan pembagian dengan nol ditangani dengan pesan kesalahan.

Rincian alur, pengujian, dan integrasi mata pelajaran ada di [LAPORAN_PROJEK.md](LAPORAN_PROJEK.md).
